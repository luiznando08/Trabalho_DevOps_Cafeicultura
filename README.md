# DevOps Lab - One-Page CI/CD

Projeto desenvolvido para a atividade prática de DevOps, aplicando deploy automatizado na AWS EC2 utilizando Docker e GitHub Actions.

## Tecnologias Utilizadas
* **Frontend:** HTML5
* **Containerização:** Docker (Nginx Alpine)
* **CI/CD:** GitHub Actions
* **Infraestrutura:** AWS EC2
